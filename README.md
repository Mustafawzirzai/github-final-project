# github-final-project

A calculator that calculates simple interest given principal, annual rate of interest, and time period in years.

## Input

- **p**: Principal amount
- **t**: Time period in years
- **r**: Annual rate of interest (percentage)

## Output

Simple interest is calculated using the following formula:

**Simple Interest = (p × t × r) / 100**

## Example

- Principal (p): 1000
- Time (t): 2 years
- Annual rate (r): 5%

Calculation:

Simple Interest = (1000 × 2 × 5) / 100 = 100

The simple interest is **100**.

## Project Purpose

This project demonstrates a simple Bash-based calculator and provides an example of using Git and GitHub for open-source collaboration.
